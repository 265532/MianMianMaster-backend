# AI模拟面试与能力提升软件需求分析

## 一、学生端

### 1. 岗位适配与职业发展测评
- **岗职双维测评**
  用户进入岗职双维测评模块后，系统引导完成多维度测评（包括心理测评和技术能力测评），最终生成综合报告，展示各维度得分及匹配建议。
- **岗位适配度模型**
  用户选择或输入目标岗位，系统自动匹配岗位知识图谱，结合用户已完成的测评数据，计算匹配百分比，并以图表形式展示能力差距（如技术能力不足、软技能缺失等）。
- **一体化分析报告**
  包含岗位适配度测评、职业心理测评、岗位技术能力测评。
- **AI生成学习培养方案**
  点击“生成学习方案”，AI根据能力短板和目标岗位要求，推荐学习路径、课程资源、练习题库，并支持动态跟踪学习进度。（相关数据保存到个人中心）

### 2. 个人中心
- **我的收藏与社区**
  - **收藏的职位**：收藏自己感兴趣的岗位。
  - **收藏的内容**：收藏的面试复盘、社群精华帖子。
  - **我的动态**：可查看在社群发布的贴子或评论记录。
- **学习与面试记录**
  - **面试历史**：列表展示最近的面试记录（含回放或复盘报告入口），支持按时间或岗位筛选。
  - **能力成长曲线**：可视化图表，展示技术能力、软技能等随时间的变化趋势。
  - **学习培养方案**：AI生成的定制化学习计划，以及课程/任务的完成进度。
  - **我的错题/收藏题库**：在刷题或面试中答错的题目、收藏的经典题目合集。
- **我的成果与报告**
  - 面试后的个人面试结果报告查看
  - 心理职业测评报告结果
  - 个人的 Offer 认证
- **基本信息**
  - 头像、姓名、学历、求职意向（目标岗位）、工作年限。
- **能力数字看板**
  - 展示与岗位的匹配度
  - 游戏学习中掌握的技能数量展示
  - 认证证书的展示
- **设置**
  - **账号安全**：手机绑定、密码修改
  - **消息通知**：面试结果推送、学习提醒、系统公告
  - **联系客服**：对接 AI 智能客服，回答问题
  - **退出登录**：销毁登录状态，若首次销毁失败，则重试一定次数

### 3. 个性化能力提升
- **游戏化学习**
  - **学习徽章发放与上链存证**：用户在学习模块中，针对特定技能完成视频学习、练习或测试后，系统自动发放该技能的学习徽章，并提示是否上链存证（区块链）。上链后生成不可篡改的存证记录，可在个人中心查看。
  - **游戏通关式面试**：用户进入游戏化面试模块，选择岗位类别和难度（如初级、中级、高级），进入关卡挑战。每个关卡包含若干面试题或模拟场景，完成后系统评分，根据得分发放相应徽章和经验值。经验值可用于解锁更高难度关卡。
  - **技能树可视化**：在技能树界面，以树状图展示目标岗位所需的各项技能。用户通过完成学习任务或答题掌握技能后，对应节点点亮（从灰色变为绿色）。未掌握技能节点可点击查看学习建议和推荐题目。
- **岗位化专属题库**
  提供 Java后端、Web前端、Python算法等专属题库。
  - **题库管理**：选择自己对应的岗位刷题。
  - **收藏夹**：点击可收藏对应岗位题目，支持取消收藏。
  - **个性化推荐**：点击生成题目，系统随机从题库抽取对应岗位题目进行练习。
  - **题库练习**：支持导入简历生成定制化题目；支持接入企业真实面试题目进行练习（可作为收费项）。
- **能力认证**
  提供刷题、专项、综合认证，生成认证报告，可与岗职测评报告联动。

### 4. 面试模块
- **面试智能体**
  - **多角色AI面试官**：支持小组面试（技术/HR/业务），可配置面试官性格（压力型/温和型/引导型），通过切换不同类型进行面试。
  - **智能追问**：面试过程中，AI面试官基于用户的简历内容和当前回答，通过本地 RAG（检索增强生成）索引实时检索知识库，生成上下文相关的追问。
  - **多模态交互**：支持语音、文字输入，实现自然对话。
  - **知识库搭建**：内置技术栈、考点、优秀回答案例。
- **多维度AI分析报告**
  - **内容分析**：技术正确性、知识深度、逻辑、岗位匹配度。
  - **答案对比**：与优秀范例高亮对比优化点；基于逆强化学习的成功案例参考。
  - **表达分析**：语速、清晰度、自信度。
  - **非言语行为分析**：微表情/肢体语言解读。
  - **报告解释**：AI 生成该份报告的依据和缘由。
- **认证报告输出**
  - **Offer认证**：AI 根据面试评分及岗位匹配度评分，评价是否发放 Offer 认证。
  - **能力证明**：对于面试中学生掌握该岗位能力的评分：
    - **评分 > 80分**：发放对应的能力证明。
    - **评分 < 80分**：显示对应知识点的不足和提升方案。
- **多轮会话记录管理**
  - 本地支持存储历史面试记录，支持随时回看。

### 5. 面试复盘社群
- **内容分享**：学生可将自己的文本报告分享至匿名社群，供其他用户或 AI 点评。
- **真题上传**：用户可上传面试真题。
- **搜索功能**：支持搜索关键词，查找相关文章或用户。
- **互动交流**：查看他人发布的文章，支持点赞、评论。
- **个人主页**：点击文章可进入作者主页，查看作者基本信息，并可点击关注以第一时间收到更新通知。

## 二、后台管理

### 1. 系统管理
- **创建用户**：选择用户类型（学生、企业）分配不同的用户权限，填写相关信息（账号，密码）。
- **状态管控**：支持禁用/启用用户账号，查看用户封禁原因与历史记录。

### 2. 用户管理
- **用户信息管理**
  - **用户列表**：支持按角色（学生/企业/管理员）、注册时间、活跃状态进行筛选查询。
  - **信息编辑**：可修改用户昵称、联系方式、权限等级，支持批量导入/导出用户数据。
  - **删除用户**：选择要删除的用户，进行二次确认后删除并提示成功。
- **数据看板**
  - **活跃统计**：对用户的在线数、活跃度进行统计和可视化展示。

### 3. 面试管理
- **面试会话管控**
  - **会话列表**：对每一个用户的面试会话分配唯一 ID 进行存储和追踪。
- **题库与流程管理**
  - **题目管理**：新增/编辑/删除面试题目，支持按岗位、难度、考察维度进行分类管理。

### 4. 学习和证书管理
- **资源库管理**
  - **资料管理**：上传和管理视频课程、文档资料、项目案例，支持按知识点标签进行分类。
- **学习进度监控**
  - **数据统计**：支持查看学生的学习完成率、知识点掌握度。
- **证书管理**
  - **证书颁发**：自动或手动为达标用户颁发证书，支持证书防伪校验功能。
